A cinematic cocktail landing page inspired by the Mazorita brand, rebuilt with Next.js and modern motion-driven UI. This project focuses on immersive storytelling, premium visuals, elegant typography, and smooth scroll-based interactions.

## ✨ Highlights

- Premium cocktail brand landing page aesthetic
- Responsive layout for desktop and mobile
- Animated sections powered by GSAP and ScrollTrigger
- Elegant typography and layered visual storytelling
- Clean Next.js app structure with TypeScript

## 🌐 Live Site

https://viseking.github.io/Mazorita_clone/

## 🛠️ Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- GSAP

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ recommended
- npm or pnpm

### Install dependencies

```bash
npm install
```

### Run locally

```bash
npm run dev
```

Then open:

```bash
http://localhost:3000
```

### Build for production

```bash
npm run build
```
